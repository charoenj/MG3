# MG3
## Devlog
1. The default value for floats and ints is 0. For bools, it is set to false as default. Strings are defaulted to null.
2. The Update method is called by Unity automatically for the scripts that feature it that are attached to GameObjects so Unity handles it during the game meaning we do not have to call it. 
3. The TimerText class uses the timer to keep track of the elapsed time and displays it on the screen for the player to see it. The Update() method is called by Unity automatically which allows us to have a timer that updates constantly.
